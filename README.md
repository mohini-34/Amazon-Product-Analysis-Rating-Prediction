# Amazon Product Analysis & Rating Prediction

This is a mini data science project based on Amazon product dataset.

In this project, I analyzed product data and built a Linear Regression model to predict product ratings using different product features like price, discount, category, etc.

The project helped me understand how real-world datasets are cleaned and used in machine learning.

---

## Things I worked on

- Data cleaning
- Handling missing values
- Feature engineering
- Category splitting
- Price and discount analysis
- Converting categorical data into numbers
- Data visualization
- Building Linear Regression model
- Model evaluation

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## Dataset Features

The dataset contains:
- Product Name
- Category
- Actual Price
- Discounted Price
- Discount Percentage
- Ratings
- Number of Reviews

---

## Machine Learning Model

I used **Linear Regression** for predicting product ratings.

Model evaluation was done using:
- MAE
- MSE
- R² Score
